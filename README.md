## Ciclo de trabajo

```bash
git status                 # ver qué cambió
git add .                  # elegir qué guardar
git commit -m "mensaje"    # guardar una versión con mensaje
git push                   # subirla a GitHub
git pull                   # traer lo que otros subieron
```
